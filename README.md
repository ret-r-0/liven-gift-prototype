# November Room

Прототип подарунка для юзерів: календар на місяць зі сценою, що оживає, і знищувач думок.

## Структура

```
index.html   розмітка: сцена (SVG), календар, знищувач
styles.css   усі стилі, кольори в блоці :root на початку
app.js       логіка: завдання, збереження прогресу, анімації знищувача
```

## Як запустити локально

**Найпростіше:** відкрий `index.html` подвійним кліком у браузері. Усе працює без сервера.

**Через локальний сервер** (потрібен Node.js):

```
npm run dev
```

і відкрий http://localhost:3000

## Що де міняти

- **Завдання на кожен день:** масив `TASKS` в `app.js` (30 пар: заголовок і підказка).
- **Підписи предметів у сцені:** масив `ITEMS` в `app.js`. Предмет №N відповідає `data-n="N"` в SVG в `index.html`.
- **Порядок появи предметів:** атрибут `data-n` у групах `<g class="it" ...>` в `index.html`.
- **Кольори і шрифти:** блок `:root` на початку `styles.css` (палітра Liven: темно-синій фон, зелена кнопка, золото для прогресу).
- **Фрази після знищення думки:** об'єкт `LINES` в `app.js`.
- **Нові анімації знищувача:** об'єкт `FX` в `app.js` + кнопка-радіо в `index.html` з тим самим `value`.
- **Фрази фенікса (коли думка повертається):** масив `PAST` в `app.js`.
- **Логотип:** у шапці стоїть тимчасовий текстовий напис `liven` (`<span class="brand">` в `index.html`). Заміни його на офіційний SVG логотипа.
- **«Сьогоднішній» день:** константа `TODAY` в `app.js` (поза листопадом 2026 вона дорівнює 13 для демо).
- **Демо-прогрес:** початкове `S={done:[2,3,5,8,9,11,12]...}` в `app.js`. Порожній масив = чиста кімната.

Прогрес зберігається в `localStorage` браузера під ключем `november-room-v1`. Щоб скинути, натисни «Empty the room» або очисти localStorage.

## Думка, яку вже відпускали

Якщо юзер пише думку, яку вже знищував, вибраний спосіб не запускається. Замість нього з попелу піднімається фенікс, забирає папірець, і юзер бачить «Look, that one's already in the past. Breathe out.» та коли саме він її відпустив.

- Порівняння не зважає на регістр, пунктуацію і зайві пробіли: `My boss is SO annoying!!` і `my boss is so annoying` це одна думка.
- Сам текст ніде не зберігається. У `localStorage` під ключем `november-room-let-go-v1` лежить лише незворотний відбиток (хеш) і дата, останні 300 записів.
- Для демо внизу вкладки є посилання «Prototype: forget every thought I've let go», воно чистить цей список.

## Деплой на Vercel

1. Залий папку в репозиторій на GitHub.
2. На vercel.com: Add New → Project → обери репозиторій.
3. Framework Preset: **Other**, Build Command порожній, Output Directory `.`
4. Deploy.

Або з терміналу: `npx vercel` у цій папці.

Нагадування: безкоштовний план Hobby лише для некомерційного використання. Для розсилки юзерам від імені компанії потрібен Pro.
